# LEET 언어이해 문항관리 프로그램 설계안

## 목적과 범위
윈도우 컴퓨터에 설치하여 HWPX 원본과 문항 정보를 관리하는 개인용 프로그램이다. 인터넷 연결 없이 사용한다. 깃허브에 게시하지 않는다. 첫 버전은 한 사람이 한 컴퓨터에서 사용하는 것을 기준으로 한다. 여러 사람이 동시에 공유 폴더의 데이터베이스를 수정하는 방식은 지원하지 않는다.

## 구현 방식
권장안은 윈도우 데스크톱 프로그램과 SQLite 데이터베이스를 결합하는 방식이다. 원본 파일과 데이터베이스는 설치 폴더와 분리한 사용자 데이터 폴더에 보관한다. 설치 프로그램을 업데이트하거나 삭제할 때 연구 자료가 함께 삭제되지 않게 한다.

대안으로 로컬 웹 프로그램은 화면 확장이 쉽지만 실행 과정에 브라우저와 서버가 필요하다. 엑셀 중심 방식은 시작하기 쉽지만 세트와 문항의 관계, 수정 이력, 원본 파일 관리에 한계가 있다. 따라서 설치형 데스크톱 방식을 우선한다.

## 세트와 문항의 관계
HWPX 파일 하나를 세트 하나로 등록한다. 세트에는 제시문 하나와 문항 세 개가 속한다. 각 문항에는 해설 하나가 연결된다. 세트 ID와 문항 ID는 자동으로 부여하고 수정하지 않는다. 입력이 덜 끝난 자료는 초안으로 저장할 수 있지만 검토 완료로 전환할 때 문항 수와 정답 등을 확인한다.

## 분류
문항 유형은 다음 네 가지다. 문항마다 하나를 선택한다.
1. 주제, 구조, 관점 파악
2. 정보의 확인과 재구성
3. 정보의 추론과 해석
4. 정보의 평가와 적용

내용 영역과 세부 과목은 세트에서 지정한다. 여러 학문이 결합된 지문을 위해 보조 과목과 검색 태그를 추가할 수 있다.

| 내용 영역 | 기본 세부 과목 |
|---|---|
| 인문 | 문학, 역사, 기타 |
| 사회 | 정치학, 경제학, 사회학, 기타 |
| 과학기술 | 물리, 화학, 생물, 기타 |
| 규범 | 법학, 철학, 기타 |

세부 과목은 사용자가 추가할 수 있다. 기존 자료가 사용하는 과목은 임의로 삭제하지 않는다.

## 관리 정보
세트: 제목, 생성 연도, 실제 등록 시각, 제시문 텍스트, 내용 영역, 세부 과목, 원문 출처, 작성자, 검토자, 검토 상태, 메모, 원본 파일 이름, 파일 해시.
문항: 세트 내 번호, 발문, 보기, 선택지, 문항 유형, 핵심 키워드, 문항 성격, 평가 목표, 문항 풀이, 정답, 정답 근거, 선택지별 해설, 함정 유형, 예상 난이도, 실제 정답률, 검토 메모.
핵심 키워드는 세트 공통과 문항 개별을 구별한다. 선택지별 해설에는 정답 여부와 진술의 타당성을 구별하여 기록한다. 부정형 발문에서는 부적절한 선택지가 정답일 수 있기 때문이다. 원문에 쓰인 ‘오답 근거’라는 표제와 해설 내용도 보존한다.
생성 연도는 파일 수정일과 구별하여 직접 입력한다. 정답률은 실제 실시 자료가 있을 때만 입력하고 예상 난이도와 구별한다. 선택지는 기본 5개로 구성한다.

## 사용, 기출, 폐기 기록
세 가지 상태는 서로 독립적으로 관리한다. 사용하면 사용일, 시험명 또는 연구명, 사용 범위, 메모를 이력으로 추가한다. 같은 자료를 여러 번 사용한 이력도 보존한다. 기출 여부에는 시험명, 연도, 회차, 문항 번호, 공개 여부를 연결한다. 기출의 기본 뜻은 실제 시험에 출제된 자료로 두고, 모의시험과 연구용 사용은 사용 구분으로 표시한다.

폐기는 자료 삭제와 구별한다. 폐기일과 사유를 기록하고 원본과 해설을 보존한다. 폐기 자료는 기본 목록에서 제외하되 검색에서 포함할 수 있다. 사용 이력은 세트 전체 또는 개별 문항에 붙일 수 있다. 세트 화면에는 문항별 사용 상태를 합산해 보여준다.

## HWPX 가져오기
원본을 데이터 폴더에 복사하여 외부 파일의 이동이나 삭제에 영향을 받지 않게 한다. 동일한 파일 해시가 이미 있으면 중복 등록을 알린다. 텍스트를 추출하고 제시문, 세 문항, 해설의 위치를 사용자가 확인하는 가져오기 화면을 제공한다. 자동 분석 결과를 확인 없이 확정하지 않는다.

첨부한 「언어이해.hwpx」의 Contents/section0.xml을 확인했다. 표, 삽입 이미지, 수식 없이 문단 텍스트로 구성되어 있다. 이 파일은 안내문 다음의 제시문, 1.·2.·3. 문항, ①~⑤ 선택지, <보기>, [해설 및 정답], 핵심 키워드, n번 문항 해설, 평가 목표:, 정답:, 제시문 근거:, 오답 근거:, 참고문헌이라는 경계를 이용하여 분리할 수 있다. 이 분석은 파일 구조 확인이며 자동 가져오기 기능을 구현하거나 검증한 결과는 아니다. 다른 HWPX 형식은 별도 확인이 필요하다. 첫 버전은 추출한 텍스트를 보여주고 각 입력란으로 배정하는 기능을 보장한다. 표, 수식, 이미지의 원본 표현은 HWPX 원본 열기로 확인한다. 원본 열기는 컴퓨터에 연결된 HWPX 프로그램을 사용한다.

## 화면과 기능
목록 화면: 세트 목록, 문항 목록, 검색어, 생성 연도, 내용 영역, 세부 과목, 문항 유형, 사용 여부, 기출 여부, 폐기 여부, 검토 상태 필터.
상세 화면: 제시문, 문항 1·2·3, 해설, 분류와 관리 정보, 사용 이력, 수정 이력.
등록 화면: HWPX 가져오기와 직접 입력. 저장 전 필수값과 정답 범위를 검사한다.
자료 관리 화면: 백업, 복원, CSV 내보내기, 세부 과목 관리.
검색은 제시문, 발문, 해설, 키워드, 제목을 대상으로 한다. CSV에는 한 문항을 한 행으로 출력하고 세트 ID로 연결한다.

## 보존과 복구
수정 시 변경 시각과 변경 내용을 기록한다. 백업은 데이터베이스와 원본 파일을 함께 포함한 ZIP으로 만든다. 복원 전에 현재 자료를 자동 백업한다. 복원 파일의 구조와 데이터베이스를 검사하고 실패하면 기존 자료를 유지한다. 최초 버전에서 별도 암호화 기능을 보장하지 않으며 윈도우 사용자 계정의 접근 권한을 사용한다.

## 검증과 배포
세트 저장과 재실행 후 조회, 문항별 분류 검색, 한글 검색, HWPX 텍스트 추출, 중복 감지, 사용 이력 누적, 폐기 필터, 백업과 복원 후 원본 일치 여부를 검증한다. 사용자 자료가 없는 상태에서 시작한다. 예시 자료를 제공할 경우 실제 자료와 구별한다.

최종 산출물은 소스 코드, 사용 설명서, 윈도우 실행 또는 설치 패키지다. 현재 실행 환경에는 윈도우 빌드 도구가 확인되지 않았으므로 설치 EXE 생성과 윈도우 실행 검증 가능 여부는 별도로 확인한다. 소스 코드나 빌드 스크립트를 검증된 윈도우 설치 파일이라고 표시하지 않는다.

## 실제 첨부 파일에 따른 보완
「언어이해.hwpx」에는 법치주의와 계몽적 자연법에 관한 제시문 하나와 세 문항이 있다. 해설에 명시된 정답은 1번 ③, 2번 ①, 3번 ④이다. 3번은 보기와 부정형 발문을 포함하며 함정 유형도 명시되어 있다. 참고문헌은 세트의 출처 정보로 보관한다. 제시문 안의 [12면] 등 원문 쪽수 표시는 삭제하지 않는다.

문항 유형과 내용 영역, 생성 연도, 작성자, 사용 여부, 폐기 여부, 기출 여부는 파일에 명시되어 있지 않다. 입력 화면에서는 ‘미입력’ 또는 ‘미확인’으로 표시한다. 가져오면서 출처의 발행 연도인 1998년을 생성 연도로 넣지 않는다. 사용 이력이 없다는 사정만으로 미사용을 확정하지 않는다. 분류 추천이 있을 경우 사용자 확인 전에는 확정 분류로 저장하지 않는다.

사진의 문항 성격, 평가 목표, 문항 풀이, 정답 해설, 오답 해설 구조도 지원한다. 텍스트 필드로 담기 어려운 원본 서식과 표시 기호는 원본 파일에서 확인할 수 있게 한다.

## 구현 전 확인 사항
이 설계의 개인용 오프라인 구조를 기본으로 한다. 대표 HWPX 파일은 확보했으며 확인형 가져오기와 해당 서식의 자동 분리를 구현 대상으로 삼는다. 설계안 확인 후 구현 계획과 프로그램 작성 단계로 진행한다.
