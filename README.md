# LEET 언어이해 문항관리

개인용 오프라인 데스크톱 프로그램입니다. 세트별 제시문 하나와 문항 1~3, 해설, 원본 HWPX를 관리합니다. 프로그램 실행에는 계정·서버·인터넷 연결이 필요하지 않습니다.

## 지금 제공하는 파일과 실행

[Windows 실행 파일 program.exe 다운로드](https://github.com/iam-1004/-/raw/refs/heads/main/program.exe)

다운로드한 파일의 SHA256은 `program.exe.sha256`에 기록되어 있습니다. 저장소가 비공개라면 GitHub에 로그인한 뒤 다운로드하세요.

Windows 10/11 64비트용 **단일 실행 파일 `program.exe`**를 제공합니다. EXE를 원하는 폴더에 저장한 뒤 더블클릭하세요. Python 설치나 ZIP 압축 해제가 필요하지 않습니다. 첫 실행에서 빈 자료실을 생성합니다. 사용자 자료는 실행 파일과 분리해 보관합니다.

이번 EXE는 Windows용 CPython 3.12.15와 PyInstaller 6.16.0을 사용해 Wine 호환 환경에서 빌드했습니다. 같은 환경에서 33개 테스트와 실제 EXE의 화면 시작, 자료 저장, 종료 후 재실행과 문항ID 보존을 확인했습니다. 실제 Windows 컴퓨터에서의 검증과 실제 HWPX 호환성 검증은 별도로 필요합니다.

소스 실행을 원하는 경우 Python 3.12(Tcl/Tk 포함)에서 `run_windows.cmd`를 실행하거나 다음 명령을 사용하세요.

```powershell
py -3.12 main.py
```

Windows에서 EXE를 다시 빌드하려면:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
```

빌드 시에는 의존성 다운로드에 인터넷이 필요하지만, 생성한 EXE 실행은 오프라인입니다. 결과는 `dist\program.exe`와 설명서를 포함한 ZIP입니다. EXE 파일 하나로 실행할 수 있습니다.

## 데이터 위치와 보존

Windows: `%LOCALAPPDATA%\LEETQuestionManager`

- `data.sqlite3`: 문항, 세트, 분류, 상태와 이력
- `originals`: 파일 SHA256을 이름으로 사용한 HWPX 원본 사본
- `backups`: 복원 직전의 자동 백업 ZIP
- `instance.lock`: 중복 실행 방지 파일. 종료 시 잠금은 자동 해제됩니다.

프로그램 폴더와 분리하므로 새 버전으로 교체해도 자료를 보존합니다. 다른 컴퓨터로 자료를 이동할 때는 ZIP 백업/복원을 사용하세요. 한 사람이 한 컴퓨터에서 사용하며 공유 폴더 DB 동시 수정을 지원하지 않습니다. 암호화 기능은 없고 Windows 사용자 계정의 권한을 사용합니다.

## 자료 등록

1. **새 세트**로 직접 입력하거나 **HWPX 가져오기**로 원본을 선택합니다.
2. 세트 탭에 제목, 제시문, 공통 키워드와 분류를 입력합니다. 문항 탭에는 발문, 보기, 선택지, 개별 키워드와 해설을 입력합니다.
3. 세트ID와 문항ID는 최초 저장 시 자동 생성되고 읽기 전용으로 표시됩니다. 문항 번호와 문항ID는 서로 다릅니다.
4. 정보가 덜 입력된 상태도 초안으로 저장할 수 있습니다. 검토 완료에는 제시문과 문항 3개, 각 발문·선택지 5개·정답·문항 유형이 필요합니다.
5. 자료를 열거나 닫기 전에 수정 내용을 저장합니다. 저장하지 않고 닫으려 하면 확인 안내가 나옵니다. 여러 창에서 같은 자료를 열어 다른 창이 먼저 저장하면, 뒤의 저장은 충돌 안내와 함께 거부됩니다. 해당 창의 수정 내용을 복사해 보관하고 자료를 다시 열어 반영하세요.

정답 번호와 선택지 진술의 타당성은 별도입니다. ‘적절하지 않은 것’ 문항은 부적절한 진술이 정답이어도 저장됩니다. 타당성은 미확인/타당/부적절 중 선택합니다. 원문의 오답 근거 표제와 본문은 별도 필드에 보존됩니다.

생성 연도와 실제 정답률이 미확인이면 입력란을 비워 두세요. 사용·기출·폐기 상태는 기본 미확인입니다. 이력이 없다고 미사용으로 처리하지 않습니다. 문항 유형과 내용 영역도 가져오기에서 추정하지 않습니다. 출처의 발행 연도를 생성 연도로 넣지 않습니다.

## HWPX 확인형 가져오기

문단 텍스트를 추출한 뒤 알려진 서식의 경계를 이용해 후보를 제시합니다. 지원 경계: 1.·2.·3., ①~⑤, `<보기>`/〈보기〉, [해설 및 정답], 핵심 키워드, n번 문항 해설, 평가 목표, 정답, 제시문 근거, 오답 근거, 함정 유형, 참고문헌.

- **추출 원문 확인 / 배정**에서 필요한 원문을 선택하고 대상 입력란에 배정할 수 있습니다. 같은 입력란에 배정하면 기존 내용이 교체됩니다.
- 자동 분리 결과를 각 문항 탭에서 수정하고 저장할 때 확인하세요. 자동 후보를 확인 없이 확정하지 않습니다.
- 구조가 다르면 경고를 표시하고 추출 원문을 보존합니다. 자동 분리 실패 시 원문을 직접 배정하세요.
- 표·수식·이미지의 원래 표현은 **원본 열기**로 확인합니다. Windows에 HWPX를 여는 프로그램과 파일 연결이 필요합니다.
- 원본 사본을 데이터 폴더에 보관합니다. 같은 SHA256의 파일은 중복 등록을 거부합니다.
- 최초 버전의 크기 제한은 압축 파일 25 MB, 내부 파일 합계 50 MB입니다. 위험한 XML 선언과 손상 파일은 거부합니다.

현재 실제 「언어이해.hwpx」는 첨부되지 않아 실자료 검증은 하지 못했습니다. 테스트에서는 별도 합성 HWPX를 만들어 ③·①·④ 정답, 3번 보기, 공통 키워드, 해설 경계를 확인했습니다. 합성 자료는 사용자 자료실에 등록하지 않습니다.

## 목록·이력·폐기

세트/문항 목록을 전환하고 제목·제시문·해설·키워드·ID를 검색하세요. 문항 목록은 세트ID가 아닌 문항ID를 표시합니다. 연도 필터에는 숫자 또는 `미확인`을 입력할 수 있습니다. 나머지 필터는 목록에서 선택합니다.

사용·기출·폐기는 독립 상태입니다. 상세 화면의 **사용 · 기출 · 수정 이력**에서 사용 이력과 기출 기록을 세트 전체 또는 특정 문항에 추가합니다. 사용 이력이 생기면 해당 문항과 세트의 사용 상태는 예로 표시합니다. 문항별 상태도 이력 탭에서 확인합니다. 반복 사용은 새 이력으로 누적됩니다.

폐기는 삭제가 아닙니다. 세트/문항의 폐기 상태를 예로 바꾸고 실제 날짜와 사유를 입력하세요. 폐기 세트 또는 문항은 기본 목록에서 제외됩니다. 폐기 자료 포함을 켜거나 폐기 여부 예로 검색하면 다시 볼 수 있습니다. 폐기 상태를 변경해도 원본·해설·이력을 보존합니다.

세부 과목 관리에서는 과목을 추가하거나 미사용 과목을 삭제할 수 있습니다. 자료가 주 과목이나 보조 과목으로 사용하는 과목은 삭제하지 않습니다.

## 백업·복원·CSV

- **ZIP 백업**: DB와 참조하는 원본 파일을 함께 저장하고 SHA256과 구조를 검증합니다.
- **복원**: 편집창을 먼저 닫고 백업 ZIP을 선택합니다. 구조·DB·원본 해시를 검증한 후 현재 자료를 자동 백업하고 교체합니다. 잘못된 백업은 기존 자료를 교체하지 않습니다. 작업 도중 전원을 끄지 마세요.
- DB·원본·잠금 파일 경로에 백업이나 CSV를 덮어쓰는 것은 거부합니다. CSV는 임시 파일에 작성한 뒤 완성된 파일로 교체합니다.
- **CSV 내보내기**: 현재 검색/필터에 맞는 문항 한 개를 한 행으로 저장합니다. 세트ID/문항ID, 공통/개별 키워드, 선택지별 정답 여부/타당성/해설을 포함합니다. Excel용 UTF-8 BOM을 사용하고 수식으로 해석될 수 있는 셀은 작은따옴표를 붙입니다. CSV는 전체 이력과 원본을 담는 ZIP 백업을 대체하지 않습니다.

## 검증

```powershell
py -3.12 -m unittest discover -s tests -v
```

저장/재조회, 고정 ID, 한글·문항별 검색, 미확인 상태, 날짜/정답률 검증, 사용 이력 누적, 폐기 필터, 과목 보호, 합성 HWPX 추출·중복, 백업/복원·해시, CSV와 GUI 저장/원문 배정/필터를 검사합니다. GUI 테스트는 화면이 없는 환경에서 건너뛰며 Windows에서는 실제 Tk 창을 생성합니다.

Windows 실기 확인 항목: 첫 실행, 저장 후 재실행, 한글 경로, 실제 HWPX 가져오기, 원본 파일 연결, ZIP 백업/복원, EXE 폴더 전체 이동. Linux의 Tk 테스트 통과는 Windows 배포 검증을 대신하지 않습니다.

현재 검증 결과: Python 3.12 / SQLite 3.53 / Tk 9.0의 Linux 환경에서 가상 화면을 사용해 **33개 테스트 통과, 건너뛴 테스트 0개**. 독립 검토에서 확인된 CSV 보호 경로·편집 충돌·복원 스키마 문제를 수정하고 재현 테스트를 통과했습니다. 추가 검증: Windows용 Python/Wine에서도 33/33 테스트가 통과했으며, 단일 EXE 빌드와 실제 EXE의 저장·재실행을 확인했습니다. 네이티브 Windows 검증과 Wine 검증은 구별합니다.
